# Application Intelligence

This directory starts with templates only. `project-bootstrapper` creates project and module
contracts from verified sources; the framework generator does not invent them.

1. Copy `_template/project-context.md` to `project-context.md`.
2. Copy `_template/module-context.md` to `<module>/module-context.md`.
3. Add approved requirements to the canonical `evidence/requirements.json`.
4. Keep unknowns explicit and requirements in `draft` until approved.

See [`../START-HERE.md`](../START-HERE.md) for the complete lifecycle.
